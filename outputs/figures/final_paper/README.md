# Final-paper visual set

This directory contains only the compact visual set intended for the main paper.

| File | Purpose | Source / provenance |
|---|---|---|
| `methodology_pipeline.svg` | Implemented frozen methodology | `docs/METHODOLOGY_FINAL.md`; pipeline implemented by `scripts/baseline_ladder_rolling_origin.py` and `scripts/segment_stability.py` |
| `predictive_performance_v1.png` | Frozen primary Crisp RFM-FCA versus Baseline Fuzzy RFM-FCA (M0), with one panel per dataset and metric | `results/baseline_ladder_rolling_origin/per_origin_metrics.csv`; generated by `scripts/generate_final_paper_figure.py` from existing per-origin values |

Segment stability and strong non-FCA baseline comparisons are retained in the authoritative table `results/final_evidence/EVIDENCE_TABLES.md`. No stability figure is retained because the available stability image uses an older protocol and includes superseded Kneedle output.

The predictive figure uses only `pooled=True` rolling-origin rows. The Online Retail II 365-day primary holdout, v2 hybrid, CDNOW, Raw RFM, LRFM, membership ablations, Kneedle/Kuznetsov, and obsolete optimization experiments are excluded.
