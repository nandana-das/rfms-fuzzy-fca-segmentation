# Final FCA research figures

Generated by `generate_final_fca_graphs.py` from the authoritative per-origin result CSVs. No experiments, training, bootstrapping, or metric recomputation were run.

## Figure sets

Each v1 and v2 performance figure is an origin-level line plot for one dataset and one metric. Each difference figure is also origin-level and uses the same dataset and origins. The separate CDNOW figures retain all three chronological 91-day origins.

| Set | Source | Selection and status |
|---|---|---|
| v1 | `results/baseline_ladder_rolling_origin/per_origin_metrics.csv` | `pooled=True`; Crisp and Baseline Fuzzy M0; frozen primary |
| v2 | `results/v2_hybrid/per_origin_metrics.csv` | `pooled=True`; Crisp, Baseline Fuzzy M0, and Hybrid; exploratory/post hoc |
| CDNOW | `results/cdnow_confirmation/per_origin_metrics.csv` | all three chronological origins; separate confirmation dataset |

The Online Retail II `2010-12-09 (primary, 365d)` holdout is validated but excluded from the rolling-origin figures. It is not mixed with the pooled 91-day origins. No pooled CDNOW value is created.

## Method styling

Styling is consistent across metrics and study versions and remains distinguishable in grayscale:

| Method | Stored identifier | Marker | Line |
|---|---|---|---|
| Crisp RFM-FCA | `crisp_rfm_fca` | circle | solid |
| Baseline Fuzzy RFM-FCA (M0) | `fuzzy_rfm_fca` | square | dashed |
| Hybrid Fuzzy RFM-FCA | `hybrid_fuzzy_fca` | triangle | dotted |

## Difference plots

Differences are descriptive, matched within the same dataset and chronological origin:

- `fuzzy_minus_crisp`: Baseline Fuzzy M0 − Crisp.
- `hybrid_minus_m0`: Hybrid − Baseline Fuzzy M0.
- `hybrid_minus_crisp`: Hybrid − Crisp.

Every difference plot includes a horizontal zero reference line. Positive values indicate that the first method in the label has the larger metric value. V1 plots show Fuzzy M0 − Crisp; v2 plots show all three requested differences; CDNOW plots show Hybrid − Baseline Fuzzy M0 only. The v2 differences are exploratory/post hoc. No visual difference is described as statistically significant.

## Output inventory

For each metric (`auc`, `spend_r2`, `invoice_r2`), the generator writes:

- `v1_{dunnhumby|online_retail}_{metric}_origins.png`
- `v2_{dunnhumby|online_retail}_{metric}_origins.png`
- `v1_{dunnhumby|online_retail}_{metric}_differences.png`
- `v2_{dunnhumby|online_retail}_{metric}_differences.png`
- `cdnow_{metric}_origins.png`
- `cdnow_{metric}_hybrid_minus_m0.png`

The former nine bar-chart files (`v1_*_comparison.png`, `v2_*_comparison.png`, and `cdnow_*_comparison.png`) were replaced by the origin-level figure set and are no longer part of the final output inventory.

## Audit and reproducibility

`graph_data_audit.csv` records 279 rows: every plotted source value plus every derived difference. Source rows identify the source CSV, dataset, origin, metric, method identifier, and full-precision source value. Difference rows identify both source methods and values and store the arithmetic difference `value_a - value_b`.

Run from the repository root:

```powershell
python generate_final_fca_graphs.py
```

The script validates required schemas, finite metrics, exact method/origin coverage, pooling flags, uniqueness, and matched rows before writing any figure.
